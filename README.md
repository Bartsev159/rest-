Робототехническая система доставки с ИИ-ассистентом

Описание проекта

Данный проект представляет собой простую модель робототехнической системы доставки.

Робот использует камеру для наблюдения за окружающей средой и ИИ-ассистента для принятия решений.

Система может двигаться вперёд, останавливаться при препятствиях и использовать режим импульса (BOOST) для их преодоления.

Цель проекта

Создать простую модель робота, который:
- получает данные с камеры
- анализирует их с помощью ИИ
- принимает решения о движении

Как устроена система

Камера
- создаёт кадры окружающей среды
- определяет наличие препятствий

ИИ-ассистент
- получает данные с камеры
- принимает решение:
  MOVE — двигаться
  STOP — остановиться
  BOOST — импульсное ускорение

Робот
- выполняет команды ИИ
- перемещается в пространстве
- может ускоряться в режиме BOOST

Режимы работы

MOVE
Робот движется вперёд

STOP
Робот останавливается при обнаружении препятствия

BOOST
Робот получает кратковременное ускорение для преодоления препятствия

Итог

Проект демонстрирует базовую работу робототехнической системы: восприятие среды, принятие решений и выполнение действий
