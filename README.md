Данный проект представляет собой концептуальную модель робототехнической системы доставки на базе наземной колесной платформы с системой видеонаблюдения и ИИ-ассистированного управления.
Система предназначена для перемещения в условиях городской среды и преодоления локальных препятствий (бордюры, неровности, участки с ограниченной проходимостью).
Основной особенностью является использование ИИ-ассистента, который анализирует видеопоток с камеры и принимает решения о движении и необходимости активации режима импульсного преодоления препятствий с помощью пропеллерного модуля.
Цель проекта:
Разработка робототехнической системы доставки с искусственным интеллектом и расширенными возможностями проходимости за счёт комбинации колесного движения и импульсного режима преодоления препятствий.
Система состоит из трёх основных модулей:
1.МОдуль восприятия
Камера на борту платформы
Получение видеопотока в реальном времени
Базовое восприятие окружающей среды
2.Модуль управления ИИ-ассистент
Анализ видеопотока с камеры
Обнаружение препятствий
Принятие решений о движении
Управление режимами работы системы
Возможность перехода в ручной режим контроля
3.Модуль исполнения
Колёсная система движения
Пропеллерный модуль импульсного преодоления препятствий
Реализация команд ИИ-ассистента
Режимы работы
ОСНОВНОЙ РЕЖИМ ДВИЖЕНИЯ
Перемещение на колесной базе
Управление ИИ-ассистентом
Непрерывный анализ видеопотока
РЕЖИМ ИМПУЛЬСНОГО ПРЕОДОЛЕНИЯ ПРЕПЯТСТВИЯ
Активируется ИИ-ассистентом
Кратковременная работа пропеллерного модуля
Создание импульса для преодоления препятствий
Используется для бордюров, неровностей и сложных участков
